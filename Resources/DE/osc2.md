Haupt-Oszillator (Standard: eine Oktave über OSC 1).

- **WAVE** — Klangfarbe: Sinus = rein, Sägezahn = hell/schnarrend, Rechteck = hohl, Dreieck = weich.
- **FREQ** — Tonhöhe.
- **AMP** — Pegel im Mix.
- **VOICES** — stapelt verstimmte Unisono-Kopien für einen fetteren Klang.
- **DETUNE** — spreizt die Voices auf (breiter, chorus-artig).
- **FB** — Self-FM-Rückkopplung; höher morpht Sinus → Sägezahn → kratzig-inharmonisch.
