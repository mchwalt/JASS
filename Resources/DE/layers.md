Zwei komplette Klänge gleichzeitig — Layer **A** und Layer **B**, gespielt von einer Tastatur.

- **A / B** (Tasten **1** / **2**) — welchen Layer das Rack zeigt und bearbeitet. Module von B haben eine violette Kopfzeile. **Beide** an: das Rack zeigt A, und jede Änderung geht auch an B — Regler verschieben B um denselben Betrag, B behält also seinen Abstand.
- **B ON** — Layer B klingt. Aus: nur A spielt (B behält seine Einstellungen).
- **MODE** — **Layer**: jede Taste spielt beide. **Split**: Tasten unterhalb von SPLIT spielen B, ab SPLIT aufwärts A. Die Tastatur zeigt die Tasten von B violett.
- **SPLIT** — die Split-Taste. **LEARN**, dann eine Taste spielen: diese Taste wird der Split-Punkt.
- **A LVL / B LVL** — Lautstärke je Layer.
- **A PAN / B PAN** — Balance je Layer: Mitte lässt den Layer, wie er ist, eine Seite macht die andere leiser.
- **LOAD B** — den Klang eines Presets in Layer B laden; Layer A, die Sequenzer und der Master-Bus bleiben.
- **A>B** — Layer B wird eine Kopie von A.

ARP und STEP SEQ spielen Layer A. RANDOM würfelt den bearbeiteten Layer (beide, wenn beide an sind); RESET in der Kopfzeile geht auf Init mit B aus.
