Zwei komplette Klänge gleichzeitig — Layer **A** und Layer **B**, gespielt von einer Tastatur.

- **A / B** (Tasten **1** / **2**) — welchen Layer du bearbeitest und hörst; der verlassene klingt aus. **B** einmal drücken: A und B; **B** zweimal schnell (Doppelklick): nur B — zurück genauso mit **A**. Module von B haben eine violette Kopfzeile; jeder Layer zeigt die Module, die er benutzt. Beide an: das Rack zeigt jedes Modul, das einer der Layer benutzt — ein Modul, das A benutzt, zeigt die Werte von A, und jede Änderung außer dem Ein/Aus geht auch an B (Regler verschieben B um denselben Betrag, B behält also seinen Abstand); ein Modul, das nur B benutzt, zeigt die Werte von B mit violetter Kopfzeile und ändert nur B. Ein Modul, das beide benutzen, hat ein kleines **A | B** in der Kopfzeile: es wählt, wessen Werte du siehst, und die Kopfzeile wird cyan (A) oder violett (B); auf B gehen Änderungen nur an B. Aus- und Einblenden und das Ein/Aus einer Zone wirken auf beide.
- **SPLIT auf der Tastatur** (Taste **3**) — Split ein / aus: Tasten unterhalb der Split-Taste spielen B, ab ihr aufwärts A, egal was A / B zeigt. **Doppelklick** (3, 3 schnell), dann eine Taste spielen: sie wird die Split-Taste; nochmal klicken bricht ab.
- **SPLIT** — die Split-Taste, ein Halbton pro Bewegung.
- **A LVL / B LVL** — Lautstärke je Layer.
- **A PAN / B PAN** — Balance je Layer: Mitte lässt den Layer, wie er ist, eine Seite macht die andere leiser.
- **Preset laden** (LOAD, F-Tasten): ein Preset mit **zwei Layern** lädt komplett — beide Layer, sein Split und seine A / B-Auswahl. Ein Preset mit **einem Layer** (alle älteren) lädt nach A und behält deinen Layer B. Ist **nur B** an, kommt nur der Klang des Presets nach B.

Jeder Layer hat seinen eigenen **STEP SEQ** und **ARP**, die diesen Layer spielen — eine Bassfigur in B und eine zweite Figur oder ein Arpeggio in A laufen gleichzeitig. Im Split füttert jede Hand das Pattern ihres Layers; ein Layer, dessen Pattern läuft, nimmt keine Live-Tasten. RANDOM würfelt den bearbeiteten Layer (beide, wenn beide an sind); RESET in der Kopfzeile geht auf Init: A ein heller Sägezahn-Stapel, B ein knackiger Sägezahn-Bass — ein Split spielt sofort zwei verschiedene Klänge.
