Formt die Helligkeit.

- **TYPE** — Lowpass (nimmt Höhen weg → dunkler) oder Highpass (nimmt Bässe weg → dünner).
- **CUTOFF** (Filter-Grenzfrequenz, Helligkeit) — Eckfrequenz, ab der gefiltert wird; zeigt den LFO-Ring, wenn der LFO darauf zielt.
- **RESO** (Betonung an der Grenzfrequenz) — Resonanz: betont die Frequenzen direkt an der Cutoff — hohe Werte klingeln/pfeifen.
- **TRACK** (Keytracking, 0–100 %) — die Cutoff folgt der gespielten Note, so bleibt die Klangfarbe über die Tastatur gleichmäßig. 0 = feste Cutoff; 100 = folgt Note für Note in Oktaven.
