Niederfrequenter Oszillator — eine langsame, automatische Bewegungs-Quelle (Vibrato, Tremolo, Wah, „Atmen"). Er hat KEIN eingebautes Ziel: route ihn über die MOD MATRIX auf ein beliebiges Ziel, wo er als Quelle auftaucht. Modulierte Regler zeigen einen Live-Ring.

- **WAVE** — Bewegungsform. **S&H** hält pro Zyklus einen neuen Zufallswert — gestuft statt fließend. **One-Shot** fährt pro Note einmal von voll auf null und hält dann; sein Ring bleibt dunkel, bis du spielst (er braucht eine Note).
- **RATE** — Geschwindigkeit (wirkt, wenn SYNC = Free). Bis zu einer Periode von 200 s; unter 0,1 Hz zeigt das Feld Sekunden pro Durchlauf.
- **SYNC** — koppelt die Rate als Notenwert ans Tempo (1/4, 1/8, Triolen `1/4T`, punktiert `1/4.` …); auf *Free* stellen, um den RATE-Regler zu nutzen. Das Tempo kommt von MASTER-TEMPO (oder dem DAW-Host — deiner Musik-Produktionssoftware).
- **DEPTH** — Stärke.
- **GLOBAL** — ein LFO für alle Stimmen statt einer pro Note: die Phase läuft weiter, eine neue Taste startet ihn nicht neu. Für eine Filterfahrt über ein ganzes Stück: GLOBAL an, Triangle, RATE auf einige Sekunden, in der MATRIX auf FILTER CUTOFF routen. In der DAW folgt ein synchronisierter GLOBAL-LFO der Songposition.

So nutzt du ihn: LFO einschalten, dann in der MOD MATRIX eine Zeile mit SRC = dieser LFO und ein DEST wählen.
