Echo effect.

- **TIME** — delay length (used when SYNC = Free; short = slapback, long = distinct echoes).
- **SYNC** (Tempo-Sync) — locks the delay time to the tempo as a note division (1/4, 1/8, triplets, dotted …); set to *Free* to use the TIME knob. Tempo comes from MASTER's TEMPO (or the DAW host).
- **FB** — feedback: how many repeats (higher = more, can build up).
- **MIX** (effect amount) — echo level against the dry signal.
