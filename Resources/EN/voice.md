Gives every voice its own small error — the difference between one sound played several times and an instrument.

- **HUMANIZE** — each note draws its own detune (up to ±25 cents) and start phase when it is struck, fixed while it sounds: the same chord never comes out identical twice. A quarter turn is subtle, full is old-analogue territory.
- **DRIFT** — slow movement per voice (up to ±12 cents, 0.05–0.5 Hz, different for each), so a held note does not stand still.

Both are also **MOD MATRIX sources** (`Voice Rnd`, `Voice Drift`), so you can route them to any target — filter cutoff, wavetable position, whatever suits.

Both at 0 = off; the sound is then exactly as it would be without this module.
