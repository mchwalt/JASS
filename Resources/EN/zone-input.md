Playing input — how notes get into the synth.

- Holds the on-screen KEYBOARD. Play with the mouse or the computer keys (a, w, s, e, … ; z / x shift the octave).
- Hide it when you play from an external MIDI keyboard to free up rack space.

**Group header controls**
- **Enable** — dims/enables every visible module in this group at once.
- **↺ Reset** — restores this group's *default module selection* (which modules are shown, their order and zone). It does not change any knob values.
- **ⓘ Info** — this help.
