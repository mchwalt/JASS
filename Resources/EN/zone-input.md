Playing input — how notes get into the synth.

- Holds the on-screen KEYBOARD. Play with the mouse or the computer keys (a, w, s, e, … ; ↑ / ↓ shift the octave).
- A MIDI keyboard is the better instrument: real velocity, every chord. Standalone: switch the device on before launching and pick it in the audio/MIDI settings — you can then hide the on-screen KEYBOARD.

**Group header controls**
- **Enable** — dims/enables every visible module in this group at once.
- **↺ Reset** — restores this group's *default module selection* (which modules are shown, their order and zone). It does not change any knob values.
- **ⓘ Info** — this help.
