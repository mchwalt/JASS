Plays a 16-step figure you write yourself, transposed by the key you hold. Hold a note and the pattern runs; the lowest held key is the root.

- **1 … 16** — pitch of each step in semitones above the root (0 = the root itself, +12 = one octave up).
- **G1 … G16** — length of that step. **0 = rest** (silent step). **1 = legato** — the note is held into the next step, no gap.
- **SYNC** — step length as a note division. Set it to *Free* to use RATE instead.
- **RATE** — steps per second when SYNC is *Free*.
- **LEN** — how many steps before the pattern repeats.

Replaces the ARPEGGIATOR: only one of the two can run, so switching this on switches that off.
