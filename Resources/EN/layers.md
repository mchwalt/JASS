Two complete sounds at once — layer **A** and layer **B**, played from one keyboard.

- **A / B** (keys **1** / **2**) — which layer you edit and hear; a layer you leave rings out. Press **B** once: A and B; press **B** twice quickly (double-click): B only — the same with **A** on the way back. B's modules have a violet header; each layer shows the modules it uses. Both lit: the rack shows every module either layer uses — a module A uses shows A's values and every change except its on/off goes to B too (knobs move B by the same amount, so B keeps its offset); a module only B uses shows B's values with its violet header and changes only B. A module both use carries a small **A | B** in its header: it picks whose values you see, and the header turns cyan (A) or violet (B); on B, edits go to B only. Hiding, showing and a zone's on/off act on both.
- **SPLIT on the keyboard** (key **3**) — split on / off: keys below the split key play B, from it up A, whatever A / B shows. **Double-click** (3, 3 quickly), then play a key: it becomes the split key; click again to cancel.
- **SPLIT** — the split key, one semitone per move.
- **A LVL / B LVL** — each layer's level.
- **A PAN / B PAN** — each layer's balance: centre leaves the layer as it is, a side turns the other side down.
- **Loading a preset** (LOAD, F-keys): a preset with **two layers** loads whole — both layers, its split and its A / B selection. A preset with **one layer** (all older ones) loads into A and keeps your layer B. With **B alone** lit, only the preset's sound goes into B.

Each layer has its own **STEP SEQ** and **ARP**, which play that layer — a bass figure in B and a second figure or an arpeggio in A run at once. In a Split each hand feeds its own layer's pattern; a layer whose pattern runs takes no live keys. RANDOM rolls the layer you edit (both when both are lit); RESET in the header returns to Init: A a bright saw stack, B a punchy saw bass — a Split plays two different sounds right away.
