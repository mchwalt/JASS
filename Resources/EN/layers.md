Two complete sounds at once — layer **A** and layer **B**, played from one keyboard.

- **A / B** (keys **1** / **2**) — which layer you edit and hear; a layer you leave rings out.
- **Press once** — adds the layer (A + B); **twice quickly** (double-click) — that layer only.
- **Both lit** — the rack shows every module either layer uses; a change goes to both, except a module's on/off.
- **Violet header** — a module only B uses: B's values, changes go to B only.
- **A | B in a header** — a module both layers use: picks whose values you see (header cyan for A, violet for B); on B, changes go to B only.
- **Hide, show, zone on/off** — with both lit, they act on both layers.
- **SPLIT on the keyboard** (key **3**) — split on / off: keys below the split key play B, from it up A, whatever A / B shows. **Double-click** (3, 3 quickly), then play a key: it becomes the split key; click again to cancel.
- **SPLIT** — the split key, one semitone per move.
- **A LVL / B LVL** — each layer's level.
- **A PAN / B PAN** — each layer's balance: centre leaves the layer as it is, a side turns the other side down.
- **Loading a preset** (LOAD, F-keys) — **B alone** lit: only the preset's sound goes into B. Otherwise a preset with **two layers** loads whole (both layers, its split and its A / B selection); one with **one layer** (all older ones) loads into A and keeps your B.

Each layer has its own **STEP SEQ** and **ARP**, which play that layer — a bass figure in B and a second figure or an arpeggio in A run at once. In a Split each hand feeds its own layer's pattern; a layer whose pattern runs takes no live keys. RANDOM rolls the layer you edit (both when both are lit); RESET in the header returns to Init: A a bright saw stack, B a punchy saw bass — a Split plays two different sounds right away.
