A low-frequency oscillator — a slow, automatic movement source (vibrato, tremolo, wah, "breathing"). It has NO built-in target: route it to any destination in the MOD MATRIX, where it appears as a source. Modulated knobs show a live ring.

- **WAVE** — the movement shape.
- **RATE** — speed (used when SYNC = Free).
- **SYNC** — locks the rate to the tempo as a note division (1/4, 1/8, triplets `1/4T`, dotted `1/4.` …); set to *Free* to use the RATE knob instead. Tempo comes from MASTER's TEMPO (or the DAW host — your music production software).
- **DEPTH** — amount.

To use it: enable the LFO, then add a MOD MATRIX row with SRC = this LFO and pick a DEST.
