A low-frequency oscillator — a slow, automatic movement source (vibrato, tremolo, wah, "breathing"). It has NO built-in target: route it to any destination in the MOD MATRIX, where it appears as a source. Modulated knobs show a live ring.

- **WAVE** — the movement shape. **S&H** holds a new random level every cycle — stepped, not smooth. **One-Shot** sweeps once from full to zero per note, then holds; its ring stays dark until you play (it needs a note). With GLOBAL on it sweeps once when the LFO is switched on or a preset loads, no note needed.
- **RATE** — speed (used when SYNC = Free). Down to a period of 200 s; below 0.1 Hz the box reads seconds per cycle.
- **SYNC** — locks the rate to the tempo as a note division (1/4, 1/8, triplets `1/4T`, dotted `1/4.` …); set to *Free* to use the RATE knob instead. Tempo comes from MASTER's TEMPO (or the DAW host — your music production software).
- **DEPTH** — amount.
- **GLOBAL** — one LFO for all voices instead of one per note: the phase runs on and a new key does not restart it. For a filter sweep over a whole piece: GLOBAL on, Triangle, RATE at a few seconds, route to FILTER CUTOFF. In a DAW a synced GLOBAL LFO follows the song position.

To use it: enable the LFO, then add a MOD MATRIX row with SRC = this LFO and pick a DEST.
