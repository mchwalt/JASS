The synth's final output stage.

- **VOL** — the final output volume.
- **TEMPO** — the internal BPM (beats per minute) that drives Tempo-Sync (locks note timing to the song tempo) (the note-division rates in LFO and DELAY). Inside a DAW the host tempo overrides this value.
- **In a DAW (VST3) this module is off and locked**: mute, level and tempo are the host's — use the track mute, the track fader and the project tempo. The stored values still apply when the same patch is opened in the standalone.
