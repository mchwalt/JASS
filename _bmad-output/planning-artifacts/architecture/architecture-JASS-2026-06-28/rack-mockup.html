JASS · Unified Rack UI — Layout Mockup

Every module is one ModuleFrame built from a declarative descriptor: a uniform header (title · enable LED · reset ↺) over a body of controls or a display, placed by the rack on a fixed 8-column grid. Three size classes only — this is the first-pass class assignment for all ~20 modules, to judge fit on a 1920×1200 window and the "from one mold" feel before any C++.

Oscilloscope + Spectrum — how wide?

Both are display-only modules. The question is footprint width. The whole layout rests on having only three size classes, so the real cost of "wider" is a fourth class.
