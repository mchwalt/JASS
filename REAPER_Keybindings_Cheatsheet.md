# REAPER Keybindings Cheatsheet

## Transport
| Shortcut | Aktion |
|---|---|
| `Space` | Play / Stop |
| `Enter` | Play / Pause |
| `R` | Aufnahme starten/stoppen |
| `Home` | Zum Anfang springen |
| `End` | Zum Ende springen |

## Navigation & Zoom
| Shortcut | Aktion |
|---|---|
| `Mausrad` | Horizontal zoomen |
| `Ctrl+Mausrad` | Vertikal zoomen |
| `Alt+Mausrad` | Horizontal scrollen |
| `Ctrl+Alt+Mausrad` | Vertikal scrollen |
| `Ctrl+Shift+Mausrad` | Track-Höhe anpassen |

## Tracks & Items
| Shortcut | Aktion |
|---|---|
| `Ctrl+T` | Neue Spur erstellen |
| `S` | Item splitten (am Cursor) |
| `Delete` | Ausgewähltes Item löschen |
| `Ctrl+Drag` | Item kopieren |
| `Alt+Drag` | Item-Inhalt verschieben |
| `Shift+Drag` | Verschieben ohne Snap |
| `Doppelklick Item` | MIDI-Editor / Item-Properties öffnen |

## Media Item Dragging
| Shortcut | Aktion |
|---|---|
| `Left Drag` | Item verschieben (ignoriert Time Selection) |
| `Shift+Left Drag` | Item verschieben (ignoriert Snap + Time Selection) |
| `Ctrl+Left Drag` | Item kopieren |
| `Alt+Left Drag` | Item-Inhalt verschieben |

## Media Item Selection
| Shortcut | Aktion |
|---|---|
| `Left Click` | Item auswählen + Edit Cursor setzen |
| `Shift+Left Click` | Bereich von Items zur Auswahl hinzufügen |
| `Ctrl+Left Click` | Item-Auswahl umschalten |
| `Alt+Left Click` | Item auswählen (Gruppierung ignorieren) |
| `Shift+Doppelklick` | Time Selection auf Item setzen |
| `Ctrl+Doppelklick` | Loop Points auf Item setzen |

## Envelope & Automation
| Shortcut | Aktion |
|---|---|
| `Left Drag` | Envelope-Punkt verschieben |
| `Shift+Left Drag` | Envelope-Punkt verschieben (ohne Snap) |
| `Ctrl+Left Drag` | Freihand Envelope zeichnen (ohne Snap) |
| `Doppelklick` | Punkt auf Standardwert zurücksetzen |

## Editing
| Shortcut | Aktion |
|---|---|
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z` | Redo |
| `Ctrl+C` / `Ctrl+V` | Kopieren / Einfügen |
| `Ctrl+A` | Alles auswählen |

## FX & Mixing
| Shortcut | Aktion |
|---|---|
| `Ctrl+Shift+F` | FX-Browser öffnen |
| `M` | Spur muten |
| `Ctrl+M` | Master-Track anzeigen |

## Sonstiges
| Shortcut | Aktion |
|---|---|
| `?` | Shortcut-Liste in REAPER öffnen |
| `Ctrl+P` | Preferences öffnen |

---
*REAPER hat insgesamt 744 Shortcuts. Vollständige Liste: Actions > Show action list (`?`)*
